# Changelog

## [v0.1.0] — 2026-07-16 — Project Scaffold & Auth

### Added
- FastAPI project with Clean Architecture folder structure
- PostgreSQL database with Alembic migrations (users table)
- User registration, login (JWT), and profile endpoints
- React project restructured with modular architecture
- Auth pages (Login, Register) with form validation and error handling
- Auth context + guarded routes (AuthGuard, GuestGuard)
- Shared Layout, Sidebar, and TopNav components
- Core UI components (Button, Card, Input, Badge)
- API client with Axios and interceptor-based token refresh
- Docker Compose (backend + frontend + postgres)
- Tailwind CSS with Bauhaus design tokens and dark mode support
